# Welcome to the TumorScript Wiki

**TumorScript** is an esoteric, biomorphic programming language that maps quantum observer effects and biological cancer progression directly into software runtime semantics.

In TumorScript:
* Variables mutate simply by being observed (read-based entropy).
* Infected variables transmit corruption to healthy variables across mathematical operations (metastasis).
* Functions decay over time if fed malignant arguments (genetic degeneration).
* Developers must orchestrate targeted medical interventions (`quarantine`, `chemo`, `apoptosis`) to extract valid computational results before the host organism suffers catastrophic organ failure.

## Core Philosophy

Traditional programming languages strive for total determinism and absolute data persistence. TumorScript treats software as a living, unstable organism:

$$V_{\text{mutated}} = V_{\text{base}} \times (1 \pm \delta)$$

Every cycle of reading data drains the stability of the program. Writing software in TumorScript is not merely expressing logic; it is a race against systemic entropy.
